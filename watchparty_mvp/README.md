# AmorellyWatch v4 — Accounts & Friends

В v4 добавлены:
- email/password аккаунты через Supabase Auth;
- уникальный @username и профиль;
- поиск пользователей и запросы в друзья;
- список друзей с online/offline статусом;
- отображение текущего просмотра с настройками приватности;
- приглашение друга в текущую комнату;
- запрос «попроситься в комнату» с подтверждением владельца;
- настройки: скрыть просмотр, скрыть название, запретить запросы;
- комнаты/чат/WebRTC из v3.3 продолжают работать даже если Supabase ещё не настроен.

## Настройка Supabase
1. Создай проект Supabase.
2. В SQL Editor выполни `supabase_schema.sql` целиком.
3. Для быстрого теста можно отключить обязательное подтверждение email в настройках Auth. Если оставить подтверждение — после регистрации пользователь получит письмо и войдёт после подтверждения.
4. В Render -> Environment добавь:
   - `SUPABASE_URL` = Project URL
   - `SUPABASE_PUBLISHABLE_KEY` = Publishable key
5. Никогда не добавляй Secret key / service_role в браузер или в публичный config.
6. Перезапусти deploy.

Если используется старый Supabase-проект с legacy ключами, вместо publishable можно временно задать `SUPABASE_ANON_KEY` — сервер v4 поддерживает оба варианта.
