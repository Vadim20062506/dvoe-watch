# Двое — Watch Party v3

## Новое

- чат фиксированной высоты рядом с видео;
- сообщения скроллятся только внутри чата;
- отдельные переключатели микрофона, звука собеседника и камеры;
- WebRTC голос + вебкамера;
- камера отображается поверх плеера;
- повторный вход после Ctrl+F5 без создания новой комнаты;
- состояние пустой комнаты хранится на сервере до 6 часов;
- прогресс сериала перенесён в меню под логотипом;
- локальная история просмотра;
- сворачивание чата и блока выбора источника.

## Важное ограничение WebRTC

Используются публичные STUN-серверы. В большинстве обычных домашних сетей этого достаточно, но в некоторых корпоративных/мобильных сетях для 100% надёжности нужен TURN-сервер.

## Аккаунты и друзья

В v3 не включены. Для настоящих аккаунтов и списка друзей нужна постоянная база данных и авторизация (например Supabase/Postgres). Это лучше делать отдельным следующим этапом.
