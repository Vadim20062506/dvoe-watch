# Двое — Watch Party MVP

Минимальный сайт для совместного просмотра вдвоём.

## Что умеет

- приватная комната по ссылке;
- максимум 2 человека в комнате;
- YouTube;
- локальный видеофайл у каждого пользователя;
- синхронизация play / pause / перемотки;
- периодическое выравнивание позиции;
- чат;
- кнопка «догнать партнёра».

## Локальный запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открой:

```text
http://localhost:3000
```

Чтобы смотреть с человеком из другого места, размести проект на Render, Railway, Fly.io или другом Node.js-хостинге.

## Быстрый деплой

### Render

1. Создай новый GitHub-репозиторий и положи туда файлы проекта.
2. В Render выбери **New → Web Service**.
3. Подключи репозиторий.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. После деплоя открой выданный HTTPS-адрес.

### Railway

1. Создай проект из GitHub-репозитория.
2. Railway автоматически определит Node.js.
3. Start command: `npm start`.
4. Включи публичный домен.

## Важно про локальные файлы

Видео не загружается на сервер. Оба человека выбирают у себя один и тот же файл, а сайт синхронизирует только время воспроизведения.

## Ограничения MVP

- состояние комнаты хранится в памяти сервера и пропадает после перезапуска;
- нет аккаунтов;
- нет голосового/видеозвонка;
- локальные файлы должны быть вручную выбраны у обоих;
- некоторые видео YouTube нельзя встраивать из-за ограничений правообладателя.

Это специально минимальная версия, которую можно развернуть за несколько минут.
